说明

所有尺寸/长度/直径常量按使用场景分类，并标注：

tunable用户可在 Settings 调整 derived由其他值推导，无法单独修改 fixed代码里写死的几何/视觉常量

SVG 示意图按真实比例绘制（基于默认值）。当用户改了 Wheel 滑杆，所有 derived 值都会跟着变。 所有派生公式都注明了来源文件 + 行号。

命中区 vs 视觉区

扇区命中半径 = reachDiameter/2（默认 285，比可见盘大 ~78pt 缓冲）。Action Arc 激活时收缩到 visibleOuterRadius（约 160），避免鼠标移向 chip 时同时拉动底层扇区高亮。死区为 deadzoneDiameter/2（56），落在 hub 内的点返回 nil。
