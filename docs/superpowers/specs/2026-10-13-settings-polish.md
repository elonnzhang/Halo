# 设置面板优化

日期：2026-10-13。范围：设置导航、通用页分组、Apps 控件布局和窗口生命周期。

## 依据与决策

正式应用的改动前截图显示：选中导航是浅色底上的白字；通用页的七组配置需要较长滚动；多个中文页的说明仍是英文；Apps 色块没有辅助功能名称。

- 用原生 source list 的选中态和键盘导航。保留固定 200pt 侧边栏、手写 split、现有材质及 macOS 12 分支，避免再次引入 toolbar/sidebar overlay。
- 通用页拆为「召唤与切换 / 外观 / 系统」，保留原有绑定、范围、默认值、写入路径与 macOS 12 对应项。分组切换短暂交叉淡入，Reduce Motion 下缩短；切换或离开时停止快捷键采集。
- 通用设置列最大宽度 760pt，大窗口保持可读行长；Apps 保留有场景色的轮盘卡片，把「全部清空」置于场景标题旁，沿用原有确认弹窗。色块保留配色，扩大点击区域并补名称/选中语义。
- 窗口标题跟随当前设置页；关闭再打开保留本次会话的尺寸。已运行的 Halo 收到 reopen 时进入设置，复用原有打开入口。关闭通知只注册一次，并在关闭后移除。
- 补齐相关 English / zh-Hans 文案。不要把用户命名的 profile 当成待翻译文本。

## 验证范围与风险

使用 `make build`、`make test`、`make app`。在此 checkout 的正式 bundle 中对比截图并操作分组、侧边栏、快捷键采集取消、空槽选择器和窗口关闭/重开；用启动参数的临时语言/主题覆盖检查 English 与 Dark，不修改用户持久偏好。

需观察：900pt 最小窗口下的 Apps 色块与 340pt 轮盘是否仍完整；分组离开后的采集是否已取消；焦点跳转到 Actions 是否仍按 bundle ID 定位。当前主机为 macOS 27，macOS 12–26 的实际视觉仍需对应系统验证。

已验证：`make build`、228 tests / 0 failures、arm64 + x86_64 `make app` 与 ad-hoc 签名。正式应用中的三个分组、侧边栏切换与动态窗口标题、快捷键采集切换到外观页时取消、Apps 命名色块与说明已检查并捕获画面。检查后原有语言、主题、热键及启动项偏好保持不变。

剩余实机检查：确认弹窗、空槽选择器、关闭/重开及窗口缩放、English / Dark。检查过程中 macOS 锁屏，Computer Use 自动解锁失败，需要用户手动解锁后继续。

## 2026-10-14：去掉可见标题栏

使用现有 AppKit 窗口控制器启用 `fullSizeContentView`，隐藏标题文字和标题栏分隔线，透明顶栏融入设置内容。保留标准关闭、最小化、缩放按钮及逻辑窗口标题。侧边栏顶部留 34pt 避让窗口按钮，顶端及非交互背景可用于拖动；右侧内容上移。使用 macOS 12 已支持的接口，材质与偏好绑定沿用原实现。

同日统一顶部 Tab：通用分组与 Apps 场景共用 `SettingsSegmentedTabs`（原生 `NSSegmentedControl`）和 `SettingsTabsHeader`，统一 360pt 切换区、28pt 控件高度及 18pt 顶距。Apps 的新建、管理、ALL 开关和计数移到下一行，Tab 固定在滚动内容外；场景多于四个时横向滚动。原有双击重命名、右键菜单及拖动排序通过对应原生等宽分段的交互层保留，辅助功能和键盘选择由原生控件承载。

补充验证：228 tests / 0 failures，另跑 `AppPreferencesProfileTests` 33/0；双架构打包通过。正式 bundle 已确认标题文字及独立顶栏消失、标准窗口按钮保留；两种 Tab 可切换，场景管理菜单可打开，双击可进入重命名并退出；清空确认弹窗及空槽选择器可打开并取消。未执行数据清空或新建场景；拖动排序、窗口移动/重开和 English / Dark 尚未全部实测。

## 2026-10-16：Apps 场景切换器改为自动换行的胶囊

**问题。** 2026-10-14 的分段控件固定为 360pt 宽，场景超过四个就放进不显示滚动条的横向滚动区（每个场景按 90pt 计宽）。无头渲染复现：7 个场景只看得到前 4 个，其余没有任何提示；12 个场景时当前场景不在可见范围内，名称还被截断（"Writ"）。另外，新建场景追加在末尾却不会被选中，超过四个时新场景既看不到也没选中。

**决策。**
- 改为自动换行的胶囊（chip）行：所有场景同时可见，不需要"可以滚动"的提示；数量增加只是多一行，窗口变宽时自动并入更少的行。切换器移入页面滚动区，不再固定在顶部。
- 否决的方案：在横向滚动上补渐隐或箭头——内容仍被藏起来；单个弹出菜单——一次只露出一个场景；左侧场景列表——900pt 最小窗口下详情区只有 699pt，现有 hero 卡片（控制列 + 340pt 轮盘）已经占满，放不下第二列；保留分段控件——它适合少量固定选项，不适合用户可增删的列表。
- 实现：`FlowLayout`（SwiftUI `Layout`，macOS 13+）只负责取尺寸和摆放，换行规则放在 `FlowGeometry`（HaloUI 纯几何，`FlowGeometryTests` 10 项）。通用页的分段控件不变。
- 头部一行：左侧场景计数，右侧 Show ALL 与管理菜单；`＋ 新建` 作为最后一个胶囊。选中态为场景色的淡底加描边（无环境色时为中性灰），与下方卡片同色。
- 交互：单击立即切换；双击就地重命名（回车提交，Esc 取消，点击其它胶囊或离开页面时保留已输入的名称）；拖动重排并显示插入标记；右键菜单提供切换（仅未选中的胶囊）、重命名、复制、删除，「⋯」菜单只管理当前场景（重命名、复制、删除），胶囊同时暴露对应的辅助功能操作。
- 行为调整：新建或复制后切换到新场景。管理菜单改用带标题的图标标签，辅助功能名固定为"管理场景"（裸图标在状态变化后会退回"更多"）。补齐 `New / Name / Create / Delete` 的 zh-Hans 文案，此前新建面板和删除按钮在中文界面里显示英文。
- 胶囊用 `.circular` 而非 `.continuous`：continuous 胶囊的发丝线描边在两端渲染出多余的竖线。

**验证。**
- `swift test`：275 项 / 0 失败（新增 `FlowGeometryTests` 10 项）；`swift build -c release --arch arm64` 通过。
- 无头渲染（NSHostingView 位图）：1 / 4 / 7 / 9 / 12 / 20 个场景，亮 / 暗，英文 / 中文，全部场景可见、换行正确。
- 用同一份 `SettingsRootView` 在独立临时进程的真实窗口里（放在虚拟屏、不抢焦点）通过辅助功能 API 检查：胶囊为 `AXButton`、当前项 `AXSelected`；`AXPress` 切换；自定义操作重命名并回车提交；新建面板创建后新场景被选中；删除确认弹窗；管理菜单复制；900×640 最小窗口下 11 个场景占两行、hero 完整。
- 合成鼠标 / 键盘事件（无头）：单击即时切换（含换行后的第二行）、双击重命名并回车提交、Esc 取消、点击其它胶囊时提交已输入的名称。

**未验证与风险。**
- 拖动重排（需要真实指针和拖放会话）只核对了代码：排序沿用 `reorderProfile`，插入标记的方向由拖动前后的下标推出。
- macOS 13–25 的实际外观以及 macOS 26 Liquid Glass 下的观感未验证；当前主机为 macOS 27。
- 没有重新生成 `dist/Halo.app`：它正在运行，`make app` 会删除并重建该 bundle。改为用同一份 release 构建组装独立 bundle id 的副本做启动检查；Settings 界面是在上述宿主窗口里验证的，不是在这份 release 二进制里逐项点出来的。

**复核修正（2026-10-19）。**
- 胶囊改用 `Button`（`.plain` 样式）包裹，取代 `onTapGesture`：此前只有辅助功能 trait 是按钮，「键盘导航」无法聚焦或按下它。无头探针（`NSPanel` + 合成事件）对比两种写法：单击、双击（选中后重命名）结果一致，两种写法的 `onDrag` 闭包都在开始拖动时触发；完整拖放会话仍需真实指针。
- 双击未选中的胶囊时第一下即切换，保留这一行为（与 Finder 一致），并写进 `SETTING.md` §3.0；只改名不切换可用右键菜单或辅助功能的「重命名…」。
- 「⋯」菜单只管理当前场景，文档原先写成与右键菜单相同，已更正。
- 轮盘旁两个分段选择器以各自的标题（Slot count / Ranking）作为辅助功能名；控制列底部恢复「每个场景独立记忆槽位数、环境色和排序方式。Halo 召出时按 Tab / ⇧Tab 切换场景。」提示，复用原有的中英文文案。
