# 设置面板优化

日期：2026-10-13。范围：设置导航、通用页分组、Apps 控件布局和窗口生命周期。

## 依据与决策

正式应用的改动前截图显示：选中导航是浅色底上的白字；通用页的七组配置需要较长滚动；多个中文页的说明仍是英文；Apps 色块没有辅助功能名称。

- 用原生 source list 的选中态和键盘导航。保留固定 200pt 侧边栏、手写 split、现有材质及 macOS 12 分支，避免再次引入 toolbar/sidebar overlay。
- 通用页拆为「召唤与切换 / 外观 / 系统」，保留原有绑定、范围、默认值、写入路径与 macOS 12 对应项。分组切换短暂交叉淡入，Reduce Motion 下缩短；切换或离开时停止快捷键采集。
- 通用设置列最大宽度 760pt，大窗口保持可读行长；Apps 保留有场景色的轮盘卡片，把「全部清空」置于场景标题旁，沿用原有确认弹窗。色块保留配色，扩大点击区域并补名称/选中语义。
- 窗口标题跟随当前设置页；关闭再打开保留本次会话的尺寸。已运行的 Halo 收到 reopen 时进入设置，复用原有打开入口。关闭通知只注册一次，并在关闭后移除。
- 补齐相关 English / zh-Hans 文案。不要把用户命名的 profile 当成待翻译文本。

## 验证范围与风险

使用 `make build`、`make test`、`make app`。在此 checkout 的正式 bundle 中对比截图并操作分组、侧边栏、快捷键采集取消、空槽选择器和窗口关闭/重开；用启动参数的临时语言/主题覆盖检查 English 与 Dark，不修改用户持久偏好。

需观察：900pt 最小窗口下的 Apps 色块与 340pt 轮盘是否仍完整；分组离开后的采集是否已取消；焦点跳转到 Actions 是否仍按 bundle ID 定位。当前主机为 macOS 27，macOS 12–26 的实际视觉仍需对应系统验证。

已验证：`make build`、228 tests / 0 failures、arm64 + x86_64 `make app` 与 ad-hoc 签名。正式应用中的三个分组、侧边栏切换与动态窗口标题、快捷键采集切换到外观页时取消、Apps 命名色块与说明已检查并捕获画面。检查后原有语言、主题、热键及启动项偏好保持不变。

剩余实机检查：确认弹窗、空槽选择器、关闭/重开及窗口缩放、English / Dark。检查过程中 macOS 锁屏，Computer Use 自动解锁失败，需要用户手动解锁后继续。

## 2026-10-14：去掉可见标题栏

使用现有 AppKit 窗口控制器启用 `fullSizeContentView`，隐藏标题文字和标题栏分隔线，透明顶栏融入设置内容。保留标准关闭、最小化、缩放按钮及逻辑窗口标题。侧边栏顶部留 34pt 避让窗口按钮，顶端及非交互背景可用于拖动；右侧内容上移。使用 macOS 12 已支持的接口，材质与偏好绑定沿用原实现。

同日统一顶部 Tab：通用分组与 Apps 场景共用 `SettingsSegmentedTabs`（原生 `NSSegmentedControl`）和 `SettingsTabsHeader`，统一 360pt 切换区、28pt 控件高度及 18pt 顶距。Apps 的新建、管理、ALL 开关和计数移到下一行，Tab 固定在滚动内容外；场景多于四个时横向滚动。原有双击重命名、右键菜单及拖动排序通过对应原生等宽分段的交互层保留，辅助功能和键盘选择由原生控件承载。

补充验证：228 tests / 0 failures，另跑 `AppPreferencesProfileTests` 33/0；双架构打包通过。正式 bundle 已确认标题文字及独立顶栏消失、标准窗口按钮保留；两种 Tab 可切换，场景管理菜单可打开，双击可进入重命名并退出；清空确认弹窗及空槽选择器可打开并取消。未执行数据清空或新建场景；拖动排序、窗口移动/重开和 English / Dark 尚未全部实测。
